Comparison

Pipeline

Each system receives only the repository and the bug report. When an example has a known answer, the answer is used after the run to score it and is never part of the prompt.

IndexAST chunks per function and method; module code in bounded chunks; imports and calls recorded
→
RetrieveBM25 search on the bug report; exact symbol lookup; import-aware callees
→
PackToken budget for the whole prompt; compress low-priority chunks; requested code is pinned
→
OrderCallers before callees, so the prompt reads like the call chain
→
Ask the modelDiagnose now, or request symbols/queries (adaptive) or call tools (agent)

Adaptive and agent systems loop back to Retrieve until the model diagnoses, a request finds nothing new, or the round limit is reached.

Compression levels

fullThe function as written.
trimmedComments and long docstrings removed; the body is intact. Requested code never goes below this.
outlineSignature, first docstring line, and return/raise/assert lines.
signatureSignature and first docstring line only.
noteOne-line stand-in for requested code that no longer fits: signature, docstring line, return lines.
