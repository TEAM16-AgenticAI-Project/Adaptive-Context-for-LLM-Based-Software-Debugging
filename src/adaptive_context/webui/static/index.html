Adaptive-Context Debugger

An LLM agent that gathers its own context, proposes a fix in every file that needs one, and checks it against the tests.

1. Pick a bug

A .zip of a Python repository (max 25 MB). Its tests only run if the server allows it.

Public HTTPS URL ending in .git, shallow-cloned on the server.

A folder on the machine running the server.

2. Describe the bug

The agent can run it, and agent + fix check reruns it (and the related tests) on every proposed fix.
